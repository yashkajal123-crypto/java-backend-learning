# Maven Basics

| Project | Purpose |
|---|---|
| `MavenDemoApp` | Minimal Maven project and standard directory layout |
| `JavaApp` | Simple app with a `Calc` class and a JUnit 5 test |
| `telusko-app` | Project created from an archetype, with JUnit 4 and `spring-core` dependencies |
| `my-webapp` | `war` packaging with the webapp archetype |

## Run
```bash
cd JavaApp
mvn clean test
mvn package
```
