# JUnit Testing

| Project | Focus |
|---|---|
| `Junit-01` | First tests: `Calc` and `BankAccount`, assertions |
| `Junit-02` | Testing a `StringReverser` outside Maven (plain project) |
| `Junit-03` | Test classes for `Calc` and `Calculator` |
| `Junit-04` | Test-driven development: `Shapes`, `SortingUtil`, array assertions |
| `Junit-05` | Service layer tests: `PurchaseCourse`, `assertTrue` |
| `Junit-06` | Exception testing and performance (timeout) tests |

## Run
```bash
cd Junit-01
mvn clean test
```
`Junit-02` is not a Maven project; add a JUnit jar to the classpath in your IDE.
