# Core Java

Single-file programs written in VS Code, one concept per file.

**Topics:** data types, operators, control flow, loops, methods, arrays, strings, OOP (inheritance, polymorphism, abstraction, interfaces, inner and anonymous classes, enums, records, sealed classes), exceptions (`throw`, `throws`, try-with-resources), collections and Comparator vs Comparable, generics-related utilities, lambdas and functional interfaces, method references, Streams API, `Optional`, parallel streams, and threads.

## Run
```bash
javac Strings.java
java Strings
```
Some files declare multiple classes, so run the class that contains `main`.
